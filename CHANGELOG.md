# Changelog

All notable changes to this project are documented in this file.

## [0.2.0] - 2026-08-20

### Added

- `SeamAuraContainer` for pointer-safe edge light inside buttons, links, cards, and compact surfaces.
- Direction-aware container pulses and independent high-range container edge controls.
- Public source synchronization, token-free release tarballs, and the `seam.tools/aura` demo deployment.

## [0.1.0] - 2026-08-13

### Added

- Initial GitHub Packages release of the React WebGL edge-light component.
- GitHub release workflow with tag-to-version validation, package inspection, and post-publication installation verification.
